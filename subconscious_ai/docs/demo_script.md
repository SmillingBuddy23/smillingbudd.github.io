# 30-60s Demo Script

1. Open terminal, run `python main.py --mode demo --duration 20`.
2. Narrate: "CPU-first local intent model with no cloud dependencies."
3. Type quickly, pause, and move/click mouse.
4. Point to console predictions, confidence, and CPU/RAM line.
5. End by running `python benchmarks/bench_latency.py` and show p50/p90/p99.
