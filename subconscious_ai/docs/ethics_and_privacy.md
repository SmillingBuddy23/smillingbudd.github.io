# Ethics & Privacy

- Non-diagnostic use only: this project is **not** a medical, mental-health, or employment diagnostic tool.
- Consent required: users must opt-in before enabling optional audio/webcam sensors.
- Default logging behavior: raw keystrokes, raw audio, and raw webcam frames are never written to disk.
- Optional recording is off by default and should use local encrypted storage only.
- Data deletion: delete local artifacts/ and any user-created encrypted recording files to remove stored data.
